============================================================
  情感陪伴 · 启动顺序（先双击哪个、后双击哪个）
============================================================

一句话：模型是一个个单独开的窗口，大脑只负责去连它们。
        关掉某个窗口 = 关掉那个模型，大脑自动降级，不会崩。

------------------------------------------------------------
一、先选你要哪种效果，别一股脑全开
------------------------------------------------------------

  A  只想打字聊天        ->  只要 1 个窗口：1 号
  B  想说话、打字都行    ->  1 号 + 4 号 + 7 号   ← 建议先跑这个
  C  还想听它出声        ->  B + 6 号 + 5 号（最麻烦，见第四节）

  直接双击 1 号可以先看界面，但要真聊就得把模型服务起起来——
  程序里没有假数据：哪个模型没起，用到它就明确报错。

二、按这个顺序双击（★ 的要先起）
------------------------------------------------------------

  顺序   双击                       看到什么算成功
  ----   -------------------------  ----------------------------------
  ★0    0-启动大模型.bat            窗口里出现 server running / 11434
        （第一次跑大模型前，还要双击一次 0-下载大模型.bat，约 5GB）
   1     4-启动情感判断.bat          [OK] 已就绪  http://127.0.0.1:8101
   2     7-启动语音识别.bat          [OK] 已就绪  http://127.0.0.1:8103
   3     6-启动GPT语音.bat           http://127.0.0.1:9880（要出声才需要）
   4     5-启动语音合成.bat          [OK] 已就绪  http://127.0.0.1:8102

  为什么模型要先起：大脑启动时会挨个"敲门"探一下。先起就能立刻连上；
  后起也能连（按麦克风或刷新会重探一次），只是状态表第一次会写"未启动"，
  容易误以为坏了。

  6 号的 GPT-SoVITS 已经装好了，在 D:/GPT-SoVITS 这个目录（12.5GB，自带 Python 和权重）。
  双击 6 号，等它打印出 http://127.0.0.1:9880，再双击 5 号，就有真人声音了。
  想换音色：把 3~10 秒人声放进 models\voices\，命名 sad.wav / happy.wav / default.wav。


------------------------------------------------------------
二·补  服务在干什么，去哪看日志
------------------------------------------------------------

  每个 bat 起的服务，输出都同时写进 data\logs\，一天一个文件：
    大脑-<日期>.log   控制台-<日期>.log   情感判断-<日期>.log
    语音识别-<日期>.log 语音合成-<日期>.log  GPT语音模型.log
  留 30 天自动清；GPT 语音模型那份超过 20MB 也自动清。

  三个看法：
  1. bat 窗口本身：窗口里滚什么，文件里就有什么（6 号也会滚了）
  2. 控制台网页 → 左边「服务日志」：点服务名切换，
     勾上「每 3 秒自动刷新」就像监视器一直看
  3. 双击 8-看日志.bat：按屏幕上的编号挑一个，
     能只看最后几行，也能一直跟着刷

  窗口关了、服务崩了，日志文件都还在，出问题先翻它。

三、怎么确认真的都活了（30 秒）
------------------------------------------------------------

  双击 9-检查是否在运行.bat，会打印这样一张表：

      情感判断   已启动   http://127.0.0.1:8101    32ms
      语音识别   已启动   http://127.0.0.1:8103    18ms
      语音合成   已启动   http://127.0.0.1:8102    24ms
      对话大模型 已启动   http://127.0.0.1:11434   40ms

  四个"已启动"就是齐了；哪个"未启动"，回去双击对应编号那个 bat。
  合成那行如果带"（模型未就绪）"，说明 6 号没起或 GPT-SoVITS 没连上。
  这张表只检查、不启动、不安装，随时可以点。


------------------------------------------------------------
四、控制台里那几个模式词是什么意思
------------------------------------------------------------

  rule       关键词规则。没开判断模型时用它兜底，认 8 类情绪，够用但不准。
  onnx       大脑进程里直接加载本机模型。会多吃 1.4GB 内存，
             8G 内存的机器别这么设——这跟"关掉 bat 就真停"是相反的。
  http       走独立服务（推荐）。地址就是你双击那个 bat 的端口，
             关窗口就真的停了，内存也真的还回去。
  mcp_http   走 MCP 连知识库（长期记忆那块）。

  想改：控制台 →「模型服务」→ 点开对应那张卡 → 改完点保存，立即生效，
  不用重启。想彻底停某个模型，关它的黑窗口最干脆。


------------------------------------------------------------
五、8G 显存的现实排法
------------------------------------------------------------

  对话大模型 8B（Q4）约 5GB；GPT-SoVITS 实测只吃 1.3GB；
  两个同时在显存里约 6.3GB，8GB 的卡放得下，还剩 1.5GB 余量。

  - 要聊天又要出声：把 GPT-SoVITS 改成 CPU 跑
    （GPT_SoVITS\configs\tts_infer.yaml 里 device 改成 cpu），慢一点但能听
  - 或者分时：先聊，想听声音再把 6 号窗口开起来
  - 判断模型、识别模型都是纯 CPU，不占显存，开着不心疼


------------------------------------------------------------
六、复制到服务器（换一台机器部署）
------------------------------------------------------------

  要带的：
    brain\  web\  tools\          代码
    6 个 bat + 本文件                启动入口
    config.yaml  requirements.txt   配置与依赖
    models\chinese-emotion-small\   判断模型 1GB
    models\sense-voice\             识别模型 229MB
    models\voices\                  参考音频（自己录，3~10 秒干净人声）
    models\IndexTTS-2\              只走 IndexTTS 才要，5.5GB

  不要带的：
    .venv\        新机器第一次双击任意 bat 会自己建，几分钟
    __pycache__    缓存
    data\         本机对话记录，带过去等于继承历史，看你要不要

  新机器上的顺序：
    1) 装 Python 3.11（3.12 装不了 IndexTTS，但其余都能用）
    2) 双击 9 号，让它自己建 .venv、装依赖、下识别模型
    3) 按第二节的顺序把窗口一个个开起来


------------------------------------------------------------
七、改东西的两处，别搞混
------------------------------------------------------------

  config.yaml     只管"服务怎么起、连哪个端口、模型放哪"。
                  改完要关掉 1 号窗口重开才生效。
  控制台页面      管人格、温度、音色、每类模型的参数。
                  点保存立即生效，不用重启，聊天窗口刷新一下就行。
