============================================================
  情感陪伴 · 启动顺序（先双击哪个、后双击哪个）
============================================================

一句话：大脑是一个进程，对话页和控制台都在同一个 8000 端口；
        模型服务没起时，用到它就明确报错或走兜底，不会造假数据。

------------------------------------------------------------
一、日常启动（两步）
------------------------------------------------------------

  1. 双击  1-启动.bat
       一个窗口同时提供：对话 /chat、语音识别 /asr、语音合成 /tts、
       控制台 /admin.html（同一个端口 8000）。
       启动器会按需拉起本地模型服务（如语音识别）；情感判断与合成
       都在大脑进程内，不再另开窗口。
       看到 [OK] 已就绪 就起来了；没看到，窗口里会写原因。

  2. 双击  2-体检.bat
       跑 tools\doctor.py，逐项说还缺什么、各服务在不在；
       只检查、不启动、不安装。

  浏览器访问：
       对话页   http://127.0.0.1:8000/
       控制台   http://127.0.0.1:8000/admin.html
       手机同一个 Wi-Fi：把 127.0.0.1 换成电脑局域网 IP，
       防火墙只需放行 8000。


------------------------------------------------------------
二、模型侧哪些要自己起
------------------------------------------------------------

  对话大模型：由你自己在 F 盘起（本机 8082，MiniCPM5-2B）。
       没起时聊天会提示模型未启动，不会返回写死的假回复。

  GPT-SoVITS（:9880）：只在要出声时需要。独立整合包自带 Python
       和权重，不在本工程 .venv 里；没起时语音请求明确报错。

  情感判断：进程内 ONNX，模型文件在 models\chinese-emotion-small\，
       不需要单独起服务；模型缺失时退回关键词规则兜底。

  语音识别：由 1-启动.bat 的启动器按需拉起（纯 CPU）；
       模型没下载时跑 tools\setup_asr_model.py --download 补。


------------------------------------------------------------
三、旧启动脚本已归档
------------------------------------------------------------

  原先的 1~9 号 bat（启动全部 / 大脑 / 控制台 / 情感判断 /
  语音合成 / GPT语音 / 语音识别 / 看日志 / 检查运行）都已归档到
  _旧启动脚本\ 目录：
    - 控制台功能已并入大脑进程，不再单独开 8001；
    - 情感判断、语音合成已改为进程内，不再单独起 :8101 / :8102；
    - 语音识别由启动器按需拉起，不再手动双击对应编号。
  这些归档脚本只留作历史参考，日常不要再双击。


------------------------------------------------------------
四、服务在干什么，去哪看日志
------------------------------------------------------------

  启动器把各服务输出同时写进 data\logs\，一天一个文件，留 30 天
  自动清；GPT 语音模型那份超过 20MB 也自动清。

  两个看法：
  1. 启动窗口本身：窗口里滚什么，文件里就有什么
  2. 控制台网页 → 左边「服务日志」：点服务名切换，
     勾上「每 3 秒自动刷新」就像监视器一直看

  窗口关了、服务崩了，日志文件都还在，出问题先翻它。


------------------------------------------------------------
五、控制台里那几个模式词是什么意思
------------------------------------------------------------

  rule       关键词规则。没开判断模型时用它兜底，认 8 类情绪，够用但不准。
  onnx       大脑进程里直接加载本机模型。
  http       走外部判断服务（地址在控制台「模型服务」卡里填）；
             本机默认进程内 onnx。
  mcp_http   走 MCP 连知识库（长期记忆那块）。

  想改：控制台 →「模型服务」→ 点开对应那张卡 → 改完点保存，立即生效，
  不用重启。


------------------------------------------------------------
六、8G 显存的现实排法
------------------------------------------------------------

  对话大模型 8B（Q4）约 5GB；GPT-SoVITS 实测只吃 1.3GB；
  两个同时在显存里约 6.3GB，8GB 的卡放得下，还剩 1.5GB 余量。

  - 要聊天又要出声：把 GPT-SoVITS 改成 CPU 跑
    （GPT_SoVITS\configs\tts_infer.yaml 里 device 改成 cpu），慢一点但能听
  - 或者分时：先聊，想听声音再把 GPT-SoVITS 整合包开起来
  - 判断模型、识别模型都是纯 CPU，不占显存


------------------------------------------------------------
七、复制到服务器（换一台机器部署）
------------------------------------------------------------

  要带的：
    brain\  web\  tools\          代码
    1-启动.bat  2-体检.bat  本文件   启动入口
    config.yaml  requirements.txt   配置与依赖
    models\chinese-emotion-small\   判断模型 1GB
    models\sense-voice\             识别模型 229MB
    models\voices\                  参考音频（自己录，3~10 秒干净人声）
    models\IndexTTS-2\              只走 IndexTTS 才要，5.5GB

  不要带的：
    .venv\        新机器第一次双击 1-启动.bat 会自己建，几分钟
    __pycache__    缓存
    data\         本机对话记录，带过去等于继承历史，看你要不要

  新机器上的顺序：
    1) 装 Python 3.11（3.12 装不了 IndexTTS，但其余都能用）
    2) 双击 1-启动.bat，让它自己建 .venv、装依赖
    3) 双击 2-体检.bat 看缺什么，再补对应模型


------------------------------------------------------------
八、改东西的两处，别搞混
------------------------------------------------------------

  config.yaml     只管"服务怎么起、连哪个端口、模型放哪"。
                  改完要关掉 1-启动.bat 窗口重开才生效。
  控制台页面      管人格、温度、音色、每类模型的参数。
                  点保存立即生效，不用重启，聊天窗口刷新一下就行。
